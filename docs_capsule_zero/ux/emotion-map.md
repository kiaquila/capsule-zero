> Sources: FVD v1.2, User Stories v1.4, Styling Guide v1.3, UX Validation v1.0.

## Emotional Arc

The journey from first visit to a completed capsule is an emotional story with increasing engagement. The arc passes through four phases:

**Attraction → Trust → Creativity → Satisfaction**

| ATTRACTION                           | TRUST                                          | CREATIVITY                        | SATISFACTION                  |
| ------------------------------------ | ---------------------------------------------- | --------------------------------- | ----------------------------- |
| Landing Page                         | Registration, Dashboard                        | Journey 1–3, Import, Search       | Result, Management            |
| _"Wow, finally something beautiful"_ | _"Everything is thought out, I'm comfortable"_ | _"I'm building my style system!"_ | _"My wardrobe finally works"_ |

## Cross-cutting Emotional Principles

### 1. Silence Over Noise

Every screen must "breathe". White space is not emptiness but confidence. If an element doesn't amplify emotion — it's superfluous.

### 2. Instant Feedback

Every user action gets a visual response: soft animation, highlight, quiet checkmark. Zero "dead zones".

### 3. Direct, Not Dictate

The tone of the interface is like a smart stylist: suggests, explains, does not impose. Blocks come with explanation and alternative.

### 4. Screenshot Test

The main quality criterion for every screen: "Will the user screenshot this and send to a friend?" If not — back to revision.

### 5. Emotion = Function

Beauty of the interface is not decoration but an instrument. Premium design reduces anxiety, increases trust, and motivates return.
