# Feature: Multilingual (i18n)

> Source: US-018 (spec.md). Exact UI texts: `docs_capsule_zero/i18n/ui-texts.md`

## Overview
- **Purpose:** Switch interface language (EN / RU in MVP v1) without page reload
- **User:** Any user
- **Entry point:** Language switcher on landing page and in profile settings
- **Languages:** EN (primary) and RU (Russian) in MVP v1. ES-AR (Argentine Spanish) is deferred globally to MVP v2.

## Product Decision

As of 2026-06-07, Spanish (`es-AR`) is removed from the active MVP v1 scope and moved to MVP v2. Keep Spanish source copy as future reference, but do not expose ES in app routing, language switchers, profile language persistence, OpenAPI enums, generated clients, or launch acceptance criteria until the MVP v2 locale scope is reopened.

## User Flow
1. User sees language switcher (landing page or profile)
2. Selects desired language from dropdown
3. All UI elements switch instantly (no page reload)
4. AI-generated content (auto-tags, descriptions) also translated
5. Preference saved in user profile

## Interface States

| State | Description | What user sees |
|-------|------------|----------------|
| Default | Current language active | Language code displayed (EN/RU) |
| Dropdown open | Selecting language | Two options with current highlighted |
| Switching | Language changing | Instant text swap, no loading state needed |

## Acceptance Criteria
1. Language switcher on landing page and in profile
2. All UI elements translated on switch
3. AI stylist content also translated
4. No page reload required
5. Language preference saved in user profile

## Implementation Notes
- i18n from Day 1 — not bolted on later
- ES-AR is MVP v2 scope and should remain inactive in MVP v1 implementation.
- All hardcoded strings must go through translation system
- UI text source of truth: `docs_capsule_zero/i18n/ui-texts.md`
- Consider next-intl or similar Next.js i18n solution

## Edge Cases
- Browser language detection → suggest matching language on first visit
- Missing translation → fall back to EN
- RTL languages → not needed for current 3 languages
