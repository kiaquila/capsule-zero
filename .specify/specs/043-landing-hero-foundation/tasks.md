## Process Memory

### Dead Ends

- **Субагенты в день перегрузки API:** 8 запусков подряд (копирайт ×2 линзы, ui-ux-designer)
  умерли на 529 Overloaded, включая ретраи с бэкоффом. Решение: ресерч и синтез инлайн главным
  агентом (WebSearch + уже прочитанный канон). Для повторения: PRODUCT-RESEARCH.md уже содержит
  большую часть нужной фактуры — субагенты тут nice-to-have, не критический путь.
- **`var()`-ссылки внутри `@theme` (Tailwind v4):** `--btn-cta-text: var(--color-black)` не
  эмитится в `:root` без `@theme inline` — тест поймал пустой токен. Конвенция файла — литералы;
  составные значения записаны литералами с комментарием эквивалентности. Не пытаться «починить»
  переходом на inline-режим ради двух токенов.
- **Tailwind v4 вырезает неиспользуемые `@theme`-переменные из эмиссии:** error-семья резолвилась
  (потребляется в `globals.css` через `var()`), а gold/CTA — пусто, потому что их пока никто не
  потребляет. Флак между прогонами усиливался залипшим reused dev-сервером. Решение: отдельный
  блок `@theme static` для ещё-не-потребляемых токенов; НЕ «чистить» его при рефакторинге — при
  реализации hero токены можно вернуть в обычный `@theme`, когда появятся потребители.
- **Точные строковые ассерты на authored-значения токенов** хрупки: LightningCSS нормализует hex
  в lower-case и может переформатировать rgba. Рабочий приём — `resolvedTokenColor()`: probe-элемент
  + каноническая `rgb()`-сериализация браузера (два разных `var()`-фоллбэка отличают «токен не
  определён» от совпадения с наследуемым цветом).

### Decisions

- **Направление:** V1 Gold on Glass (эволюция glass-канона) — фаундер, 2026-07-16; тёмная V2 /
  serif V3 / светлая V4 отклонены (архив в `html-prototypes/landing-v2/index.html`).
- **Копирайт:** K2 с правками фаундера — «Создай свою / гардеробную капсулу» + «Загрузи несколько
  фото любимых вещей — и узнай, что добавить, чтобы образов на каждый день стало больше» (без
  точки; «к ним» убрано); CTA «Попробовать бесплатно», без стрелки, без микро-подписи. EN-пара
  зафиксирована в прототипе.
- **Ошибки:** E4 сигнальный `#FF5449`, выбран из четырёх живых кандидатов (коралл E1 / терракота
  E2 / роза E3 / сигнальный E4); текст на скрим-чипах — отдельная ступень `#FF7A70` (база на
  скриме ≈4.1–4.7:1 — ниже AA, ступень ≈5.1:1). Скрим-контракт §9.7 не изменился.
- **`--btn-danger-*` пересажен** на `255,84,73`: старая семья `rgba(255,80,60,*)` отличалась от
  новой error-базы суб-перцептуально — «одна красная семья» вместо двух (проверка «нет дублей»).
- **Гостевой CTA ведёт в несуществующий пока инструмент** → живой `/app`-лендинг в этом слайсе
  не трогаем; прототип — контракт для следующего слайса.
- **Прототипный хром** (RU/EN-свитчер, специмены) — не продакшн; специмен ошибок оставлен только
  в архивных страницах и v1b, в финале v1c удалён по решению фаундера (значения зафиксированы в
  §9.11 и токенах).
